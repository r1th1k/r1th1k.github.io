# r1th1k.github.io

The website of r1th1k, on GitHub Pages: https://r1th1k.github.io/

- `black-tie/` is the page of Black Tie, a free card game for Android. It has the download link, the install steps, and the [privacy policy](https://r1th1k.github.io/black-tie/privacy.html).
- Black Tie is also on itch.io: https://r1th1k.itch.io/black-tie
- The Releases of this repository hold the Black Tie APK files.
- `assets/` has the shared style sheet and the fonts. The fonts are Poiret One and Josefin Sans, under the SIL Open Font License (see `assets/fonts/`).

To report a problem with Black Tie, open an issue in this repository.
